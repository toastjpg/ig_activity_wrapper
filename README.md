Opens liked posts/reels under /your_activity/interactions/likes/ in a new tab.

Post urls are generated from thumbnail image src. Image media ids are converted to shortcode urls based on this [conversion](https://stackoverflow.com/questions/24437823/getting-instagram-post-url-from-media-id). 

Basically [instahancer.js](https://github.com/schalkburger/instahancer/blob/main/instahancer.user.js) but a Chrome Extension. 


Usage
1. `git clone` this repo
2. Navigate to "Manage Extensions" page in Chrome
3. Turn on Developer Mode
4. Load unpacked and select the cloned repo folder
